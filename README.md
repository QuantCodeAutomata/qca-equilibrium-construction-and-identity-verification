# UBI Financial Equilibrium

Numerical construction and verification of continuous-time general equilibrium with Universal Basic Income policy. Based on a theoretical model with I agents, Brownian motion, BSDE pricing, and UBI redistribution.

## Experiments

1. **Equilibrium construction** — Solve for and verify the baseline equilibrium.
2. **Labor comparative statics** — Analyse how equilibrium labor supply responds to parameter changes.
3. **Figure 2 kappa/r reproduction** — Reproduce the kappa/r plot from the theoretical paper.
4. **Deterministic welfare analysis** — Compute welfare metrics in the deterministic limit.
5. **Extreme policy comparison** — Compare outcomes under extreme UBI policy configurations.
